# First Response Time

First Response Time (FRT) measures how quickly an agent replies to a new case. The clock starts when the case is opened and stops at the first agent response. Weekends are not excluded in the current definition.

Regional FRT targets differ because operating hours differ: EMEA targets 4 hours, APAC targets 8 hours, and AMER targets 4 hours.

# Case lifecycle

A case is open until an agent marks it closed. The case_extension custom object stores a severity value of high, medium, or low for each case.

# Data handling

Customer contact email addresses are collected for service delivery only. Analytics and AI answers must never expose or filter on them.
